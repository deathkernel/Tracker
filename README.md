# UPSC Prelims 2027 — Study Dashboard

A lightweight, responsive checklist dashboard for tracking UPSC Prelims preparation.

## Run locally

No installation or build step is required.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Start ticking daily tasks and PYQ topics.

## Features

- Dashboard summary: days to target, topics completed, study hours and study days.
- Daily checklist with automatic progress calculation.
- Subject-wise progress across all 9 subjects and 65 mapped topic entries.
- Topic search, subject filter and pending/completed filter.
- 27-week preparation roadmap.
- Daily study log for hours, MCQs, CSAT practice and notes.
- Weekly targets and recent study history.
- JSON export/import backup and reset controls.
- Responsive layout for desktop, tablet and mobile.
- No framework, dependencies, server or API key required.

## Data and privacy

Progress is stored in the browser's `localStorage` on the device and browser where the dashboard is used. It does not automatically sync between devices or browsers. Use **Export backup** regularly and **Import backup** to restore it elsewhere.

## Topic data note

The topic counts are approximate editorial PYQ mappings supplied for this personal study plan. They are not official UPSC topic-wise statistics and should not be treated as a prediction of future paper distribution.

## Exam target

The dashboard is configured for 23 May 2027. Confirm the date and all exam notices against the official UPSC website.
